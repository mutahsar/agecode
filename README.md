# لوحة التحكم المرئية لبناء المواقع - AgeCode

## نظرة عامة

منصة متقدمة لبناء المواقع بشكل مرئي باستخدام تقنيات حديثة، مع محرر سحب وإفلات قوي يشبه n8n، ولكن مخصص لبناء المواقع مع إمكانيات متقدمة للتخصيص والربط مع قواعد البيانات والعمليات الحسابية.

## المميزات الرئيسية

### 🎨 المحرر المرئي
- واجهة سحب وإفلات سهلة الاستخدام
- أنواع عقد متعددة: صفحات، مكونات، عمليات حسابية، قواعد بيانات، API
- ربط العقد ببعضها بطريقة مرئية
- معاينة حية للتغييرات
- خريطة مصغرة للتنقل السريع
- أدوات تكبير وتصغير وملائمة العرض

### 🧮 محرك العمليات الحسابية
- تنفيذ عمليات حسابية معقدة باستخدام Math.js
- دوال محاسبية جاهزة:
  - حساب الضريبة (VAT)
  - حساب الخصومات والنسب
  - العمليات الإحصائية (المجموع، المتوسط، الحد الأدنى/الأقصى)
  - الفوائد البسيطة والمركبة
- دعم المتغيرات والصيغ الديناميكية
- تنفيذ شروط منطقية

### 🗄️ نظام قاعدة البيانات
- محول اتصال ديناميكي
- دعم PostgreSQL, MySQL, MongoDB (قيد التطوير)
- واجهة مرئية لإنشاء وتنفيذ الاستعلامات
- عمليات CRUD جاهزة

### 🎯 أنواع العقد المتاحة

#### 1. عقدة الصفحة (Page Node)
- إنشاء صفحات جديدة للموقع
- تحديد المسار (Route)
- اختيار نوع التخطيط (افتراضي، كامل، شريط جانبي)
- ربط المكونات بالصفحة

#### 2. عقدة المكون (Component Node)
- مكونات UI متنوعة: أزرار، نماذج، جداول، مخططات، نصوص، صور
- إعدادات مخصصة لكل مكون
- إدارة الأحداث والتفاعلات
- تخصيص الأنماط

#### 3. عقدة العملية الحسابية (Computation Node)
- كتابة صيغ حسابية مخصصة
- ربط المدخلات من عقد أخرى
- إخراج النتائج لاستخدامها في عقد أخرى
- دعم العمليات المحاسبية المعقدة

#### 4. عقدة قاعدة البيانات (Database Node)
- الاتصال بقاعدة البيانات
- تنفيذ استعلامات SQL
- عمليات CRUD (إنشاء، قراءة، تحديث، حذف)
- ربط البيانات بالمكونات

#### 5. عقدة API (API Node)
- الاتصال بواجهات برمجية خارجية
- دعم جميع أنواع الطلبات (GET, POST, PUT, DELETE, PATCH)
- إدارة الرؤوس والبيانات المرسلة
- تعيين الاستجابات للمتغيرات

## التقنيات المستخدمة

- **Frontend Framework**: Next.js 14+ with App Router
- **محرر مرئي**: React Flow
- **إدارة الحالة**: Zustand
- **قاعدة البيانات**: Prisma + PostgreSQL
- **مكونات UI**: Shadcn/ui + Tailwind CSS
- **العمليات الحسابية**: Math.js
- **الأيقونات**: Lucide React
- **اللغة**: TypeScript

## البدء

### المتطلبات الأساسية

- Node.js 18+ 
- npm أو yarn أو pnpm
- PostgreSQL (اختياري للاتصال بقاعدة البيانات)

### التثبيت

1. استنساخ المشروع:
```bash
git clone https://github.com/mutahsar/agecode.git
cd agecode
```

2. تثبيت التبعيات:
```bash
npm install
```

3. إعداد متغيرات البيئة:
```bash
cp .env.example .env
```

4. تحديث ملف `.env` بإعدادات قاعدة البيانات الخاصة بك (اختياري):
```env
DATABASE_URL="postgresql://user:password@localhost:5432/agecode"
```

5. تشغيل خادم التطوير:
```bash
npm run dev
```

6. افتح المتصفح وانتقل إلى:
```
http://localhost:3000
```

## الاستخدام

### إنشاء صفحة جديدة

1. افتح المحرر من الصفحة الرئيسية
2. انقر على زر "صفحة" في لوحة الأدوات
3. ستظهر عقدة صفحة جديدة في المحرر
4. انقر على العقدة لفتح لوحة الإعدادات
5. قم بتعيين اسم الصفحة والمسار والتخطيط
6. احفظ التغييرات

### إضافة مكونات

1. انقر على زر "مكون" في لوحة الأدوات
2. اختر نوع المكون من الإعدادات
3. اربط المكون بالصفحة عن طريق سحب خط من الصفحة إلى المكون

### إنشاء عملية حسابية

1. انقر على زر "عملية حسابية" في لوحة الأدوات
2. افتح إعدادات العقدة
3. أدخل الصيغة الحسابية، مثل:
```javascript
(price * quantity) * 1.15  // إضافة 15% ضريبة
```

### أمثلة على الصيغ الحسابية

#### حساب الضريبة:
```javascript
price * 0.15
```

#### حساب الإجمالي مع الضريبة:
```javascript
price + (price * 0.15)
```

#### حساب الخصم:
```javascript
price - (price * (discount / 100))
```

#### حساب المتوسط:
```javascript
(value1 + value2 + value3) / 3
```

## الدوال الحسابية المتاحة

| الدالة | الوصف | مثال |
|--------|-------|------|
| `calculateVAT(amount, rate)` | حساب الضريبة | `calculateVAT(100, 0.15)` → 15 |
| `calculateTotalWithVAT(amount, rate)` | الإجمالي مع الضريبة | `calculateTotalWithVAT(100, 0.15)` → 115 |
| `calculateDiscount(amount, percent)` | حساب الخصم | `calculateDiscount(100, 10)` → 10 |
| `calculateTotalAfterDiscount(amount, percent)` | الإجمالي بعد الخصم | `calculateTotalAfterDiscount(100, 10)` → 90 |
| `sum(array)` | مجموع الأرقام | `sum([1, 2, 3])` → 6 |
| `average(array)` | المتوسط | `average([10, 20, 30])` → 20 |
| `min(array)` | أصغر قيمة | `min([5, 2, 8])` → 2 |
| `max(array)` | أكبر قيمة | `max([5, 2, 8])` → 8 |
| `round(number, decimals)` | التقريب | `round(3.14159, 2)` → 3.14 |

## API Endpoints

### Projects
- `GET /api/projects` - جلب جميع المشاريع
- `POST /api/projects` - إنشاء مشروع جديد
- `PUT /api/projects` - تحديث مشروع

### Nodes
- `GET /api/nodes` - جلب جميع العقد
- `POST /api/nodes` - إنشاء عقدة جديدة
- `PUT /api/nodes` - تحديث عقدة
- `DELETE /api/nodes` - حذف عقدة

### Compute
- `POST /api/compute` - تنفيذ عملية حسابية
- `GET /api/compute` - جلب الدوال المتاحة
